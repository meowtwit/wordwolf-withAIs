月夜のワードウルフ　macOS 版の使いかた
========================================

Node.js などのインストールは不要です。このフォルダだけで動きます。
（AI と話すためにインターネット接続が必要です。Apple シリコンの Mac にも Intel の Mac にも対応）


■ 最初の1回だけ
-----------------
1. ダウンロードした ZIP をダブルクリックして展開し、できた「wordwolf」フォルダを
   「書類」や「デスクトップ」など好きな場所に移す。
2. フォルダの中の start.command をダブルクリック。
   「開発元を確認できないため開けません」「Apple は検証できませんでした」と出たら:
     → 「完了」を押して閉じる
     → アップルメニュー →「システム設定」→「プライバシーとセキュリティ」
     → 下のほうの「start.command は…」の横の「このまま開く」を押す
     → もう一度 start.command をダブルクリック →「開く」
   （admin.command と stop.command も、最初の1回だけ同じ操作が必要なことがあります）

   どうしても開けないときは「ターミナル」を開いて次の1行を入力して Enter
   （wordwolf フォルダをデスクトップに置いた場合）:
     xattr -dr com.apple.quarantine ~/Desktop/wordwolf


■ ゲームをはじめる
-----------------
・start.command をダブルクリック
  → Google Chrome（または Microsoft Edge）が入っていれば、全画面でゲームが開きます。
  → どちらもなければ Safari で開きます。control + command + F で全画面にしてください。
  展示には Google Chrome がおすすめです（全画面のまま、ほかの画面に移りにくい）。
・ターミナルのウィンドウは閉じてかまいません（ゲームは裏で動き続けます）。
・マイクボタンを最初に押したとき、マイクの許可を聞かれたら「許可」を押してください。
  Mac 本体から「"Google Chrome" がマイクへのアクセスを求めています」と出たら「OK」。


■ 設定を変える（スタッフ用）
-----------------
・admin.command をダブルクリックすると、管理画面がふつうのウィンドウで開きます。
・キャラクターの名前・性格・話し方、AI の APIキー、1ゲームに出る AI の人数、
  放置したときにタイトルへ戻るまでの時間などを変えられます。
・「保存する」を押すと、次のゲームから反映されます。
・お客さんに触られたくないときは、管理画面で PIN を設定してください。


■ AWS（Amazon Bedrock）の AI を使う
-----------------
Gemini の回数制限にかかるときは、AWS のクレジットで使える Amazon Bedrock に切り替えられます。
1. AWS にログインして Amazon Bedrock のコンソールを開く（リージョンは「東京」）
   https://console.aws.amazon.com/bedrock/home#/api-keys/long-term/create
2. 「API キー」→「長期 API キーを生成」でキーを作り、コピーする
3. 管理画面の「AI との接続（Amazon Bedrock / AWS）」にキーを貼り付ける
4. 「キャラクター全員を Bedrock にする」→「保存する」→「接続テスト」
おすすめのモデルは Amazon Nova 2 Lite（global.amazon.nova-2-lite-v1:0）です。
Claude など Amazon 以外のモデルは AWS Marketplace 経由の請求になり、
AWS のクレジットが使えないことがあります。

■ 終わるとき
-----------------
1. ゲーム画面で command + Q（全画面のブラウザが閉じます）
2. stop.command をダブルクリック（ゲームの本体が止まります）


■ Mac の電源を入れたら自動でゲームを出したいとき
-----------------
「システム設定」→「一般」→「ログイン項目と機能拡張」→「ログイン時に開く」の「＋」で
start.command を追加してください。


■ こまったとき
-----------------
・「AI がずっと考えている」「定型文しか話さない」
  → 管理画面の「接続テスト」を押してください。
    APIキーが正しいか、インターネットにつながっているかがわかります。
    Gemini の無料枠は 1分15回・1日の回数にも上限があります。
    たくさんの人が遊ぶ展示では、有料プランへの切り替えをおすすめします。
    有料にしたら、管理画面の「1分あたりの呼び出し上限」を 0（制限なし）に。
・「ゲームを起動できませんでした」
  → data/server.log に理由が書いてあります。
・「別のアプリがポート 3939 を使っています」と出る
  → Mac を再起動してから start.command を押してください。
・前の版の画面（設定がたくさん並んだ画面）が出る
  → このフォルダの start.command を使っているか確認してください。新しい版は
    http://localhost:3939/ で開きます（前の版は 3000 番でした）。
・声が読み上げられない
  → 「システム設定」→「アクセシビリティ」→「読み上げコンテンツ」で、
    日本語の声（Kyoko など）が入っているか確認してください。
・設定ファイルの場所: data/settings.json
  （APIキーが入っているので、人に渡したりネットに上げたりしないでください）
