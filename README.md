# 月夜のワードウルフ（Word Wolf with AIs）

人間1〜2人 ＋ 独立したAI 2〜4人（標準は3人）で遊ぶ、ブラウザ版ワードウルフです。
AIそれぞれに性格とモデルを設定でき、AI同士が疑い合ったり、人間を誘導したりします。
声で話しかけることができ、AIの発言は読み上げられます。
ゲーム終了後には、**各AIの「誰が怪しいか」の推理の変化と作戦**がすべて公開されます。

## 遊び方

```bash
cp .env.example .env   # 使う AI のキーを書く（なくても簡易AIで遊べる）
npm start              # → http://localhost:3000
```

- 依存パッケージはありません（Node.js 20 以上が必要）。`npm install` も不要です。
- APIキーがなくても、**オフライン（ルールベース）AI**ですぐに遊べます。
- マイク入力は Chrome / Edge / Safari で使えます。ブラウザがマイクを使えるのは `localhost` か `https://` のページだけです。

## ゲームの流れ

| ターン | 内容 |
| --- | --- |
| 順番決め | ルーレットで全員の話す順番をランダムに決める。そのあと人間は自分のお題を確認 |
| 1ターン目 | 順番に **ひとこと** ずつ話す |
| 2ターン目 | 順番に、誰か1人を選んで **質問**。聞かれた人がその場で答える |
| 3ターン目 | **1分間の自由会話**。`@名前` で呼びかける（複数OK、`@all` で全員） |
| 4ターン目 | **全員一斉投票**。票はそろってから一斉に公開。最多票の人が追放される |
| 逆予測 | ウルフが見破られても、多数派のお題を当てれば **逆転勝利** |

- 同票なら、同票の人たちの中からもう一度一斉投票。それでも同票なら誰も追放されず、ウルフの勝ちです。
- 人間2人の場合は1台の端末を交代で使います。お題の確認と投票は「ほかの人は見ないで」画面を挟んで1人ずつ行います。
- 声で話すときは `@` を言えないので、**名前を呼べば呼びかけ**として扱います（「ミオはどう思う？」）。「みんな、〜」で始めると全員への呼びかけです。

### 3ターン目（自由会話）が混雑しないための決まり

`src/game.js` の `FREE_TALK` で調整できます。

- AIは **1人ずつ** しか考えません（同時に話さない）。AIの発言どうしは最低4秒あけます。
- **人間に呼ばれたAIが最優先**。`@all` なら AI 全員が1人ずつ順番に答えます。
- AIがAIを呼ぶ連鎖は2段まで。返事待ちの列は4人まで（同じAIは重複させない）。
- 同じAIが続けて話すのは7秒あける（人間に呼ばれたときは除く）。自由会話で話せるのは1人5回まで。
- 誰も呼ばれずに人間が話したら、まだ話していないAIが1人だけ反応します。
- 5秒だれも話さなければ、AIが誰かを `@名前` で呼んで話題を振ります。
- 時間切れの直前に考え始めた発言は、1.5秒の猶予を過ぎたら捨てます。

### API の回数制限への対策

無料枠には「1分あたり◯回」の上限があります。Gemini Flash-Lite の無料枠は **15回/分**（プロジェクト・モデルごと。エラーメッセージで確認）なので、既定では余裕を見て 12回/分 に抑えています。1日あたりの上限もあるので、[AI Studio](https://aistudio.google.com/rate-limit) で確認してください。

- サーバーが直近1分の呼び出し回数を数え、上限を超えそうなら呼ぶ前に待ちます（`GEMINI_RPM` などで変更。0 で制限なし）。
- 自由会話では、残りの枠を残り時間に均等に配ります。投票と逆予測の分は先に取っておきます。
- 枠がないときは、人間に呼ばれた分にだけ答えます。上限でまだ呼べないAIは後回しにして、呼べるAIが先に話します。
- 有料プランにしたら、`.env` で `GEMINI_RPM` を上げ、`AI_MIN_INTERVAL_MS=2000` くらいまで下げるとテンポが上がります。

1ゲームでAIを呼ぶ回数は、AI 3人で約20〜25回です（ひとこと3、質問と回答で約6、自由会話10前後、投票3、逆予測1）。

## AI の設計

```
ゲーム管理サーバー（src/game.js）… 順番・お題配布・ログ・自由会話の交通整理・投票集計・勝敗判定
   ├─ AI 1（慎重・分析型）独立した記憶
   ├─ AI 2（積極・質問型）独立した記憶
   └─ AI 3（直感・攪乱型）独立した記憶
```

- 各AIに渡すのは **自分のお題・公開された会話ログ・自分の性格・自分の前回の推理** だけ（`aiView()`）。
  他人のお題やウルフの正体は渡さないので、構造的に漏れません（テストで確認済み）。
- AIは毎回次の JSON を返します。`speech` 以外はゲーム中は非公開です。
  ```json
  { "speech": "@ミオ それって屋内でも楽しめる？",
    "suspicions": { "h1": 0.15, "ai2": 0.70, "ai3": 0.15 },
    "strategy": "ミオの反応を確認する",
    "wolf_self": 0.2 }
  ```
- AIがお題そのものを言ってしまったら「〇〇」に伏せます。
- 1・2ターン目でAPIが失敗したら、そのターンだけオフラインAIが代わりに話します。自由会話では、不自然にならないよう黙ってスキップします（どちらも結果画面に表示）。

### 性格プリセット

慎重・分析型 / 積極・質問型 / 直感・攪乱型 / 陽気・天然型 / 皮肉屋（`src/ai.js` の `PERSONALITIES` で追加できます）

## 対応AIプロバイダ

| id | サービス | 環境変数 | 既定モデル |
| --- | --- | --- | --- |
| `mock` | オフライン（APIなし） | — | ルールベース |
| `gemini` | Google Gemini API | `GEMINI_API_KEY` | `gemini-flash-lite-latest` |
| `groq` | GroqCloud | `GROQ_API_KEY` | `llama-3.3-70b-versatile` |
| `openrouter` | OpenRouter | `OPENROUTER_API_KEY` | `meta-llama/llama-3.3-70b-instruct:free` |
| `huggingface` | Hugging Face Inference Providers | `HF_TOKEN` | `meta-llama/Llama-3.1-8B-Instruct` |
| `cerebras` | Cerebras Inference | `CEREBRAS_API_KEY` | `llama3.1-8b` |
| `ollama` | ローカル（Ollama など OpenAI 互換） | `OLLAMA_BASE_URL` | `qwen2.5:7b` |

- Gemini は返事の速い Flash-Lite を既定にしています。`gemini-flash-latest`（3.8 Flash）は、試したときに1回の返事に60秒以上かかりました。
- 既定モデルは `*_MODEL` 環境変数か、画面の「モデル名」欄で変更できます。提供されるモデルや無料枠は変わりやすいので、各サービスで最新の情報を確認してください。
- AIごとに別のプロバイダを選べます。
- APIキーはサーバー側（`.env`）にだけ置き、ブラウザには送りません。
- **各サービスの利用規約（年齢条件など）を必ず確認してから使ってください。** 無料枠では、送った内容がサービス改善に使われる場合があります。

## 公開（デプロイ）するとき

- Node.js が動く場所ならどこでも動きます（Render、Railway、Fly.io、自分のPCなど）。起動コマンドは `npm start`、ポートは環境変数 `PORT` です。
- APIキーは `.env` をアップロードせず、サービスの「環境変数」設定に入れてください。
- ゲームの状態はサーバーのメモリ上にあり、6時間で消えます。サーバーは1台で動かしてください（複数台に分けるとゲームが見つからなくなります）。
- 身内や展示で遊ぶ前提の作りで、ログイン機能はありません。URLを知っている人は誰でも遊べます。

## 開発

```bash
npm test     # ゲーム進行・情報漏洩・自由会話の交通整理・投票/決選/逆転・回数制限のテスト
npm run dev  # ファイル変更で自動再起動
```

```
server.js          HTTP サーバー + API
src/game.js        ゲーム進行（ターン・自由会話の交通整理・投票・判定・公開状態のフィルタ）
src/ai.js          AIの性格・プロンプト・JSON解析・フォールバック
src/providers.js   各AI APIの呼び出しと、1分あたりの回数制限
src/mockAI.js      オフラインAI
src/topics.js      お題ペア（20組）
public/            フロントエンド（HTML/CSS/JS、音声入力と読み上げ）
```

### API

| メソッド | パス | 内容 |
| --- | --- | --- |
| GET | `/api/config` | 使えるプロバイダと性格の一覧 |
| POST | `/api/games` | ゲーム作成 `{ humans:[{name}], ais:[{name,personality,provider,model}] }`。順番もここで決まる |
| GET | `/api/games/:id` | 公開状態（終了前はお題・ウルフ・AIの推理を含まない） |
| POST | `/api/games/:id/word` | 人間プレイヤーのお題確認 `{ playerId }` |
| POST | `/api/games/:id/start` | ルーレットのあと、1ターン目を始める |
| POST | `/api/games/:id/advance` | 1・2ターン目で、手番のAIを動かす |
| POST | `/api/games/:id/speak` | 人間のひとこと・回答 `{ playerId, text }` |
| POST | `/api/games/:id/ask` | 人間の質問 `{ playerId, targetId, text }` |
| POST | `/api/games/:id/say` | 自由会話の発言 `{ playerId, text }`（AIはサーバーが自動で話す） |
| POST | `/api/games/:id/vote` | 人間の投票 `{ playerId, targetId }`（全員そろうとAIが投票し集計） |
| POST | `/api/games/:id/guess` | 見破られた人間ウルフの逆予測 `{ playerId, guess }` |
