月夜のワードウルフ　Windows 版の使いかた
==========================================

Node.js などのインストールは不要です。このフォルダだけで動きます。
（AI と話すためにインターネット接続が必要です）


■ 最初の1回だけ
-----------------
1. ダウンロードした ZIP を右クリック →「プロパティ」→ 下のほうの
  「許可する」にチェック →「OK」
   （これをしないと、起動のたびに警告が出ることがあります）
2. ZIP を右クリック →「すべて展開」。デスクトップなど好きな場所に置く。


■ ゲームをはじめる
-----------------
・start.bat をダブルクリック
  → 少し待つと、ゲームが全画面で開きます。
・「Windows によって PC が保護されました」と出たら
 「詳細情報」→「実行」を押してください。
・マイクボタンを最初に押したとき「マイクの使用を許可」を聞かれたら
 「許可」を押してください（次からは聞かれません）。
・タスクバーに「WordWolf-Server」という黒いウィンドウが出ます。
  これがゲームの本体なので、閉じないでください（最小化のままでOK）。


■ 設定を変える（スタッフ用）
-----------------
・admin.bat をダブルクリックすると、管理画面がふつうのウィンドウで開きます。
・キャラクターの名前・性格・話し方、AI の APIキー、1ゲームに出る AI の人数、
  放置したときにタイトルへ戻るまでの時間などを変えられます。
・「保存する」を押すと、次のゲームから反映されます。
・お客さんに触られたくないときは、管理画面で PIN を設定してください。


■ AWS（Amazon Bedrock）の AI を使う
-----------------
Gemini の回数制限にかかるときは、AWS のクレジットで使える Amazon Bedrock に切り替えられます。
1. AWS にログインして Amazon Bedrock のコンソールを開く（リージョンは「東京」）
   https://console.aws.amazon.com/bedrock/home#/api-keys/long-term/create
2. 「API キー」→「長期 API キーを生成」でキーを作り、コピーする
3. 管理画面の「AI との接続（Amazon Bedrock / AWS）」にキーを貼り付ける
4. 「キャラクター全員を Bedrock にする」→「保存する」→「接続テスト」
おすすめのモデルは Amazon Nova 2 Lite（global.amazon.nova-2-lite-v1:0）です。
Claude など Amazon 以外のモデルは AWS Marketplace 経由の請求になり、
AWS のクレジットが使えないことがあります。

■ 終わるとき
-----------------
1. ゲーム画面で Alt キーを押しながら F4 キー（全画面が閉じます）
2. stop.bat をダブルクリック（ゲームの本体が止まります）


■ PC の電源を入れたら自動でゲームを出したいとき
-----------------
1. Windows キー + R を押して「shell:startup」と入力 → Enter
2. 開いたフォルダに、start.bat のショートカットを入れる
   （start.bat を右クリック →「その他のオプションを表示」→「ショートカットの作成」
    でできたものを移動）


■ こまったとき
-----------------
・「AI がずっと考えている」「定型文しか話さない」
  → 管理画面の「接続テスト」を押してください。
    APIキーが正しいか、インターネットにつながっているかがわかります。
    Gemini の無料枠は 1分15回・1日の回数にも上限があります。
    たくさんの人が遊ぶ展示では、有料プランへの切り替えをおすすめします。
    有料にしたら、管理画面の「1分あたりの呼び出し上限」を 0（制限なし）に。
・「Another program is using port 3939」と出る
  → 別のアプリが同じ番号（3939）を使っています。PC を再起動してから start.bat を押してください。
・前の版の画面（設定がたくさん並んだ画面）が出る
  → このフォルダの start.bat を使っているか確認してください。新しい版は
    http://localhost:3939/ で開きます（前の版は 3000 番でした）。
・声が読み上げられない
  → Windows の「設定」→「時刻と言語」→「音声認識」/「言語」で
    日本語の音声が入っているか確認してください。Edge で開くと自然な声になります。
・設定ファイルの場所: data\settings.json
  （APIキーが入っているので、人に渡したりネットに上げたりしないでください）
